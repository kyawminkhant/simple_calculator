# Simple Calculator

A desktop calculator built with Python and Tkinter. It supports everyday arithmetic, common one-number operations, and calculator memory functions.

## Features

- Addition, subtraction, multiplication, and division
- Square, square root, reciprocal, negation, and percentage
- Multi-step calculations with an expression display
- Memory controls: `MC`, `MR`, `M+`, `M-`, and `MS`
- Clear-entry, clear-all, backspace, decimal input, and division-by-zero handling

## Requirements

- Python 3.8 or newer
- Tkinter, which is included with most Python installations
- No third-party packages

## Run

```bash
git clone https://github.com/kyawminkhant/simple_calculator.git
cd simple_calculator
python calculator.py
```

On some Linux distributions, install Tkinter first:

```bash
sudo apt install python3-tk
```
